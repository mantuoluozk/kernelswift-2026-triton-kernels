## 本项目参赛配置

- 赛道形式：个人赛。
- 目标芯片：海光 BW1000。
- 开发方式：可使用 KernelSwift 生成初始实现，并继续手工优化。
- 基准实现：每道题给出的 PyTorch `reference.py`。
- 优化实现：每道题目录中的 `solution.py`，入口类为 `ModelNew`。

## 评测规则

- 必须先通过正确性校验，否则不进入性能排名。
- 核心性能指标为相对 PyTorch reference 的 Speedup（加速比）。
- 禁止通过异常捕获、条件分支等方式绕过自定义算子，或在实际路径中完全 fallback 到 PyTorch 内置算子。
- 加速比相同时，按提交时间排序。
- 提交代码必须提供与参考实现构造参数、`forward` 参数兼容的 `ModelNew`。
- 文件编码要求 UTF-8，推荐 Python 3.10。

本仓库保存的官方评测器位于 `evaluator/auto_bench.py`。本项目统一使用 `warmup=200`、`repeat=500` 和中位数记录成绩。

## 作品提交内容

官方说明要求作品至少包含：

- 算子优化代码；
- README 文档；
- 环境配置文件；
- 运行脚本；
- 性能测试结果。

官方快照中的邮件提交地址为 `deeplink@pjlab.org.cn`，也可按官方要求提供 PR 链接。正式提交前应再次打开官方赛道页面确认最新方式。

## 本仓库约定

每个 `taskXX_*` 目录都是自包含单元：

- `reference.py`：PyTorch 基准实现；
- `solution.py`：Triton 优化实现；
- `benchmark.py`：本地精度和性能诊断；
- `README.md`：优化原理、实测数据和复现命令。

BW1000 容器环境由 `platforms/bw1000/docker_create.sh` 创建或进入，全部实测结果汇总在根目录 `README.md`。
