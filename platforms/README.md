# 芯片平台目录

本目录按比赛支持的芯片型号保存实现。每个平台使用独立子目录，内部包含平台环境、运行脚本、性能结果以及 10 个任务的代码。

新增平台时使用小写英文目录名，例如 `ascend_a2`、`muxi_c500` 或 `mlu590`，并保持任务目录名称与 `bw1000` 一致。只有经过该型号硬件正确性和性能测试的代码才能写入对应平台的成绩表。
